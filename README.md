# Mug & Munch

Website for Mug & Munch, a café in Islamabad serving coffee, burgers and wraps. **Sip. Bite. Repeat.**

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run preview  # serve the build
```

Owner settings: `src/config/site.ts`. Menu, prices and deals: `src/data/`. Photos go in `public/images/<category>/<slug>.webp`.
Project status and architecture: see `claude.mind.md`.
